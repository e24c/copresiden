# 型3　現場だより

今日の出来事・季節の話・お店の様子から、社長の想いを伝える型。

## 入稿で出してもらうもの

| 区分 | 項目 |
| --- | --- |
| 必須 | 写真か動画（1〜3点）、何があったか（一言） |
| 共通の確認 | 写っている人の了解があるか |

## 構成（長さの目安：30〜45秒・仮）

1. 場面（写真・動画）
2. 何があったか
3. 社長の想い・気づき
4. 締めの一言

## 画面

お客様の写真・動画が主役。AIの写真は使わない。

## 点検の決まり

- [ ] 写っている人の了解が「あり」になっているか
- [ ] お客様や取引先を特定できる情報が出ていないか
- [ ] 写真の中に出してはいけないもの（名札、書類、画面など）が写っていないか
- [ ] 締めは一文だけか
