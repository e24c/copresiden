# 型2　よくある質問

お客様から実際に聞かれることに答える型。

## 入稿で出してもらうもの

| 区分 | 項目 |
| --- | --- |
| 必須 | お客様からの質問、答えの要点 |
| あれば | 参考動画の画面収録 |

## 構成（長さの目安：40〜60秒・仮）

1. お客様の言葉で質問を出す（台帳の「お客様の言葉」を使う）
2. 答え
3. 補足（よくある勘違い、気をつけること）
4. 相談・来店をうながす一言

## 画面

カード中心。質問の文字を大きく見せる。

## 点検の決まり

- [ ] 質問は、お客様が実際に使う言葉になっているか
- [ ] 個別の判断に聞こえる言い方を避けているか（「必ず〜」ではなく「一般的には〜」）
- [ ] 業種の表現の決まりを守っているか
- [ ] 締めは一文だけか
