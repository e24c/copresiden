# 型4　商品・サービス紹介

何を頼める店・会社なのか、商品やサービスを伝える型。

## 入稿で出してもらうもの

| 区分 | 項目 |
| --- | --- |
| 必須 | 商品名・サービス名、写真 |
| あれば | 特徴、資料やページのURL |
| 共通の確認 | 写っている人の了解、メーカーの画像の使用許可 |

## 構成（長さの目安：30〜45秒・仮）

1. 何か（一言）
2. 特徴3つ
3. どんな人に向くか
4. 案内（相談・予約）

## 画面

お客様の写真が主役。

## 点検の決まり

- [ ] 業種の広告の決まりを守っているか（この型が一番触れやすい）
- [ ] 料金を出してよいか、台帳で確かめたか
- [ ] メーカーの画像の使用許可が「あり」になっているか
- [ ] 効果の言い方は3段階のどれかになっているか

注意：業種の決まりが `docs/rules/expression.md` に用意されていない業種では、この型は作らない。
