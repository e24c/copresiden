# 型1　ひとことメモ

社長が知っていること・店でいつも話していることを、一つだけ伝える型。

## 入稿で出してもらうもの

| 区分 | 項目 |
| --- | --- |
| 必須 | 話したいこと（一言）、または参考動画の画面収録（どちらか一つ以上） |
| あれば | 伝えたい点 |

## 構成（長さの目安：40〜60秒・仮）

1. 問いかけ（最初の1秒で文字を1文字ずつ出す）
2. 答え
3. 理由（必要なら「したら／しないと」の比べをイラストで入れる）
4. 締めの一言

## 分割（連続もの）

伝えることが多くて1本に収まらないときは、何話かに分ける（A.EN のテストで決めた形）。

- 入稿で「分割してよい」とされたとき、または型の長さに収まらないときに分ける
- 形：やり方ごとに1話ずつ（例：3話）、最後の1話で全体を紹介する（例：4話め）
- 各話に「話数の見出し」を付ける（例：「ブラシでトントン①｜今日の表情ケア」。①②③のあと、全体を紹介する回）
- 各話の終わりに、次の話の予告を一言入れる（例：「次回は、耳の後ろのトントンです」）。最後の話は予告なし
- 何話に分けたか、各話の中身は作業記録に書く。承認は1話ずつ

## 画面

写真かカード。見た目の業種は写真を主役にする。

## 点検の決まり

- [ ] 話題は一つだけか
- [ ] 数字・効果は裏取りの4分類に通したか
- [ ] 業種の表現の決まりを守っているか
- [ ] AIの写真を使った場合、道具・手・位置の誤りがないか
- [ ] 締めはシリーズの決まりどおりか（案内なしなら一文だけ。案内ありなら手本 ep1 の形まで）
- [ ] 分割した場合、話数の見出しと次回の予告が合っているか
