# 型1　ひとことメモ

社長が知っていること・店でいつも話していることを、一つだけ伝える型。

## 入稿で出してもらうもの

| 区分 | 項目 |
| --- | --- |
| 必須 | 話したいこと（一言）、または参考動画の画面収録（どちらか一つ以上） |
| あれば | 伝えたい点 |

## 構成（長さの目安：40〜60秒・仮）

1. 問いかけ（最初の1秒で文字を1文字ずつ出す）
2. 答え
3. 理由（必要なら「したら／しないと」の比べをイラストで入れる）
4. 締めの一言

## 画面

写真かカード。見た目の業種は写真を主役にする。

## 点検の決まり

- [ ] 話題は一つだけか
- [ ] 数字・効果は裏取りの4分類に通したか
- [ ] 業種の表現の決まりを守っているか
- [ ] AIの写真を使った場合、道具・手・位置の誤りがないか
- [ ] 締めは一文だけか
