# 裏取りのルール

参考動画や一言に出てくる数字・期間・効果は、台本に使う前に調べて4つに分ける。

| 分類 | 扱い |
| --- | --- |
| 出典あり | 使う。出典を作業記録に残す |
| 言い伝え | 「〜と言われています」として使う |
| 投稿者の独自の数字 | 使わない |
| 分からない | 使わない |

## お客様が送ってきた参考動画

- 参考動画で紹介しているやり方・効果は、送ってきたお客様が認めた内容（公認）として扱う。上の4分類で「使わない」にしない
- お客様は「この動画の内容を自分の言葉で伝えたい」と思って送ってきている。内容を落とすと動画の意味がなくなる
- 回数・時間などの数字は、言い切らずに目安として言う（例：「1日20回くらい」「20回を目安に」）
- 「予防」「解消」などの言い切りは、「対策」「〜が気になる方に」などに置き換える（`expression.md`）
- 業種の表現の決まりで使えない言葉は、決まりの言い換えを使う
- ただし、税金・法律・医療に関わる内容は、公認でも「出典あり」だけを使う

- 分けた結果は作業記録に残し、承認のときに本人が見られるようにする
- 業種によっては「出典あり」だけを使う（例：税金・法律・医療に関わる内容）
