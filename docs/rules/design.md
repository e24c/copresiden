# デザインのルール

A.ENテスト（2026年11月）で決まったこと。型ごとの違いは `templates/` に書く。

- 縦長 1080×1920
- アバターは小さめ（左下）。オープニングだけ大きくする
- アバターをはずませる動きは使わない（「落ち着きがない」と不評だった）
- 最初の1秒：問いかけを1文字ずつ出し、アバターが手で示すポーズ
- 字幕は大きめ（54px）。小さいと読めない
- 締めの案内（コメント・保存・フォローのお願い）を入れるかは、シリーズごとに事前に決めてもらう（`series.md` の「締めの案内」）
  - 入れないシリーズ：締めは短い一文だけ。案内・お願い・最後の画面を重ねない
  - 入れるシリーズ：手本 ep1 の形が上限（テストで「ぎりぎりくどくない」とされた）。声は次回の予告のあとに「感想はコメント欄へ。保存とフォローをして、見返してね。」、画面は締めの場面の上に案内の札を1枚（「感想はコメント欄へ、保存・フォローをして見返してね！」）。これ以上は足さない（`docs/reference-ep1.md`）
- 見た目の業種（美容など）は写真を主役にする。イラスト中心だと見られにくい
- 投稿の説明欄に「AI音声」と書く
