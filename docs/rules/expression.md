# 表現のルール

## 共通

- 根拠のない数字や、大げさな言葉は使わない
- 効果の言い方は3段階で書き分ける
  1. 出典あり：そのまま言う
  2. 言い伝え：「〜と言われています」と言う
  3. 本人の体験：「私のお店では〜」「私は〜と感じています」と、本人の体験として言う
- 効果をぼかしすぎない。伝わらない動画は出す意味がない（A.ENテストでの指摘）
- 他人の動画・記事の文章や言い回しをそのまま使わない。本人の言葉で語り直す

## 業種ごとの決まり

### 美容（化粧品・美容の広告）

| 使わない | 言い換え |
| --- | --- |
| 育毛・発毛・抜け毛が減る・薄毛を改善 | 分け目・生え際・ボリュームが気になる方へ |
| 髪が増える | 髪にハリ・コシを |
| 頭皮を元気に | 頭皮にうるおいを／頭皮を健やかに保つ |
| アンチエイジング・若返る・再生 | エイジングケア（年齢に応じたお手入れ） |

- 施術の前と後を比べる写真は使わない。「したら／しないと」の比べはイラストで見せる
- 急な抜け毛・産後の抜け毛が続く方などには、皮膚科への相談をすすめる一言を入れる

### その他の業種

まだ決めていない。新しい業種のお客様を受ける前に、その業種の広告の決まりを調べてここに足す。
