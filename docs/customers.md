# 顧客管理のルール

2026-11-20 に高田さんと決めたこと。

## 1. 顧客台帳（正本）

- 置き場所：SharePoint サイト `CoPresiden` のリスト「顧客台帳」
- 会社名・連絡先・契約内容などの個人情報と、入稿の合言葉は、顧客台帳だけに書く。このリポジトリ（公開）には書かない
- このリポジトリに書いてよいのは、顧客コードと、人が見分けるための短い呼び名（例：A.EN）まで

### 列

| 列 | 種類 | 例 | 夜の処理で使うか |
| --- | --- | --- | --- |
| 顧客コード（タイトル列） | 1行テキスト | C0001 | 使う |
| 呼び名 | 1行テキスト | A.EN | 使う（知らせ・記録） |
| 会社名 | 1行テキスト | | 使わない |
| 社長名 | 1行テキスト | | 使わない |
| 連絡先（電話） | 1行テキスト | | 使わない |
| 知らせメールの宛先 | 1行テキスト | | 使う |
| 状態 | 選択肢 | 契約済み／面談済み／素材あり／運用中／停止／解約 | 使う |
| 契約日 | 日付 | | 使わない |
| プラン | 選択肢 | | 使わない |
| シリーズ数 | 数値 | 1〜3 | 使わない |
| 声・顔の使用の同意日 | 日付 | | 使う（空なら作らない） |
| 入稿の合言葉 | 1行テキスト | 推測できない英数字10文字 | 使う（振り分け） |
| 合言葉の発行日 | 日付 | | 使わない |
| SharePoint のフォルダー | 1行テキスト | C0001_AEN | 使う |
| 解約日 | 日付 | | 使わない |
| 解約時の扱い | 選択肢 | 消す／返す | 使わない |
| メモ | 複数行テキスト | | 使わない |

## 2. 顧客コード

- 契約を結んだときに付ける。`C` と4桁の連番（C0001、C0002…）。一度付けたら変えない。解約したお客様のコードも使い回さない
- 契約のあとの作業は、すべて顧客コードで扱う

| 場所 | 名前 |
| --- | --- |
| SharePoint（InformationExchange） | `<顧客コード>_<呼び名>`（例：`C0001_AEN`）の下に `01_入稿`・`02_素材`・`03_完成`・`04_承認記録` |
| このリポジトリ | `customers/<顧客コード>/`（台帳 `ledger.md`、シリーズ設定 `series.md`、作業記録 `work/`） |
| 声・アバター | 非公開の置き場所（`docs/assets.md`、未決定） |
| 作業記録・承認記録・知らせメール | 顧客コードを書く |

## 3. 入稿の合言葉

- 入稿フォームの URL の末尾 `?textbox20=<合言葉>` で渡す（Jotform の隠し項目。入稿の PDF では「お客様ID」と出る）
- 合言葉は顧客コードとは別にする。URL が漏れたら、合言葉だけを作り直す（フォルダーなどの名前は変えない）
- 夜の処理は、合言葉を顧客台帳で顧客コードに引き当てる。台帳にない合言葉、または古い合言葉の入稿は振り分けず、高田さんに知らせる

## 4. 状態と夜の処理

| 状態 | 意味 | 夜の処理 |
| --- | --- | --- |
| 契約済み | 契約を結び、顧客コードを付けた | 作らない |
| 面談済み | 台帳・シリーズ設定ができた | 作らない |
| 素材あり | 声とアバターができた | 作らない（試作は高田さんの指示があれば作る） |
| 運用中 | 入稿を受け付ける | 作る |
| 停止 | 一時的に止めている | 作らずに知らせる |
| 解約 | 契約が終わった | 作らずに知らせる。素材は「解約時の扱い」に従い消すか返す |

- 「声・顔の使用の同意日」が空のお客様は、状態にかかわらず作らない

## 5. 契約から運用までの順番

1. 契約 → 顧客台帳に行を足し、顧客コードを付ける（状態：契約済み）
2. SharePoint にお客様のフォルダーを作る。このリポジトリに `customers/<顧客コード>/` を作る
3. 面談 → 台帳・シリーズ設定（状態：面談済み）
4. 声とアバターを作る（別の工程）→ 同意日を書く（状態：素材あり）
5. 入稿の合言葉を作り、入稿 URL をお客様に渡す（状態：運用中）

## 6. 夜の処理用の書き出し（2026-11-20 決定）

この作業場所の Microsoft 365 の道具は、SharePoint のリストを読めない（ファイルは読める）。そのため Power Automate で、リストの変更のたびに、夜の処理に要る列だけを CSV に書き出す。

- 正本はリスト。CSV は直さない（次の書き出しで上書きされる）
- 書き出し先：SharePoint サイト `CoPresiden` のドキュメントライブラリ `System` の `customers.csv`。`System` はお客様と共有しない
- 書き出す列（この順・この見出し）：`code`（顧客コード）、`name`（呼び名）、`notify_to`（知らせメールの宛先）、`status`（状態）、`consent_date`（声・顔の使用の同意日）、`token`（入稿の合言葉）、`folder`（SharePointのフォルダー）
- 会社名・社長名・電話・契約の内容は書き出さない
- フロー：「項目が作成または変更されたとき」→「複数の項目の取得」→「CSV テーブルの作成」→「ファイルの作成」
- リストの行は消さない（消してもフローが動かない）。契約が終わったら状態を「解約」にする
- 夜の処理は、最初に `customers.csv` を読む。読めない・見出しが違うときは作らず、高田さんに知らせる
