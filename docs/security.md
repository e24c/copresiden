# 安全のルール

- パスワード、APIの鍵、アクセストークンは、このリポジトリ・作業記録・チャットに書かない
- 声のモデルは本人そっくりに話せる。共有しない。お客様のフォルダーの外に出さない
- 解約のときは、声のモデル・アバター・台帳を消すか、お客様に返す
- 完成動画の閲覧リンクは期限つきに限る。期限のない外部共有は作らない
- 参考動画（画面収録）と見直し用の素材（`01_入稿/<送信ID>/見直し/`）は、採用か不採用が決まったら消す（確認は2回までなので、長くても2回目の確認まで）
- Jotform（検証で使う入稿フォーム、海外の会社）には、受け取ったファイルを残さない。SharePointに移ったら消す
- 投稿は、お客様が承認したものだけ。パスワードは預からず、権限を付けてもらう
