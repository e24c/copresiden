# 手本の動画（美容師あやのひとことメモ ep1）との差

2026-11-20、高田さんが別のチャット（テスト動画作成）で作ったショート動画を手本として受け取った。いまの `engine/make_video.py`（v7）との差を、まず洗い出したもの。

## 手本の動画の中身

- 41.2秒、縦長 1080×1920、30fps
- 流れ（話していること）
  1. 問いかけ：「眉間のしわ、クセになってない？」
  2. やり方：「眉間を ブラシでトントン」「ブラシは縦に、やさしく」
  3. 理由：「眉間には、印堂というツボがあって、気持ちを落ち着かせると言われています」
  4. 前と後：「そのままだと…」こわばった表情 →「トントンすると」表情がふっとやわらかく
  5. 本人の体験：「私は寝る前にやると、寝つきがいいんです」
  6. 次回の予告：「次回は、耳の後ろのトントンです」
  7. 案内：「感想はコメント欄へ。保存とフォローをして、見返してね」
- 音：声のあいまは静か（-45〜-56dB）。BGM は入っていないか、ごく小さい
