## 1. 声の学習プロセスの設計（なまりのチューニング）

- 記録：2026-11-20（高田さん）
- 状態：未着手
- 何が起きたか
  - A.EN（C0001）の声のモデル（Style-Bert-VITS2 2.7.0 JP-Extra、学習100回目）で読み上げると、発音がなまって田舎臭い話し方になる（学習53回目も同じ）
  - 文章から決めるアクセント（音の高低）は標準語どおりにモデルへ渡せていた（「まいにち」「こつこつ」「つづける」「だいじ」で確認）。ライブラリの版（2.5.0／2.7.0）による違いも無かった
  - 読ませ方の調整（話し方の揺れを小さく、抑揚を2割弱める）では良くならず、初期の設定（A 標準）が一番ましだった
- 原因の見立て：学習データ。モデルが、渡したアクセントより、録音の話し方を強く覚えている
  - 録音が少ない：学習は100回で1900歩、1回あたり4件なので、学習に使った文は約76件（数分ほど）と見られる
  - 録音が普段の話し方（会話・地元の抑揚）だった可能性
- 学習プロセスで決めること
  1. 録音の台本：標準語の読み上げ用の文章（例：音素のバランスが取れたコーパスの文）を使うか、本人の普段の話し方を残すか（本人らしさとのかね合い）
  2. 録音の量：目安10〜20分以上。面談の録音（約7分）だけでは足りない
  3. 録音の質：静かな場所、同じマイク、1文ずつ、読み間違いの取り直し
  4. 書き起こしの確かめ：学習用の文章と録音が一致しているか
  5. 学習の設定：回数、どの回のモデルを選ぶか（聞き比べの手順）
  6. 出来の点検：決まった試験文（アクセントを間違えやすい言葉を含む）を読ませて、本人と高田さんが聞いて合否を決める
- 関係：`docs/assets.md`（置き場所）、`copresiden-assets` の `C0001/README.md`（いまのモデル）

## 3. アバター画像の作り方の決まり

- 記録：2026-11-20
- 状態：未着手
- テスト版の画像で見つかったこと
  - 同じ服の中で、肌の色味と顔の形が少しずつ違う（口を切り替えるたびにちらつく）
  - 服ごとにそろっていないポーズがある（white に「こちらへ」が無い、gray に「口を大きく開ける」が無い）
  - 背景が透明ではない。白い背景の JPEG は自動で切り抜けるが、白のTシャツは背景と同じ色なので服まで消える（2026-11-20）
- 決めること：画像の作り方（同じ元の画像から口・目だけを描き変える、など）、必ずそろえるポーズの一覧、受け取りの点検
- 関係：`docs/assets.md` の2

## 4. 参考動画の動作の読み取り

- 記録：2026-11-20（高田さんの指摘）
- 状態：方針は決定。Claude の側の対策は未着手
- 何が起きたか：A.EN の参考動画の2つ目のセルフケア（ブラシで頭皮に刺激を与える）を「頭皮を指で持ち上げる」と読み取った。道具を手と取り違えたまま台本と画像を作り、動画の確認で指摘された
- 難しいところ
  - 1秒ごとのコマを読む方法では、手元の細かい動き（道具か手か、押すかとかすか）を見落としやすい
  - 承認は完成した動画で1回だけなので、読み取りの誤りが最後まで残る
  - 元の動画を確かめ直せない：Jotform の入稿は決まりどおり消している。SharePoint の動画は、いまの Microsoft 365 の道具では読めない
- 決定（2026-11-20 高田さん）：社長の手順は増やさない。動作の表を承認の知らせに載せることはしない。読み取りの誤りは、完成した動画の確認で指摘してもらう。確認は2回まで、2回目でも通らなければ不採用（`CLAUDE.md` の7）
- Claude の側でできること（社長の手順は増えない）
  1. 読み取りの結果を「動作の表」（何秒／道具／体のどこ／どう動かす／言っている効果）にして作業記録に残す。手元が動く場面は、1秒に数コマを拡大して読む
  2. 見直し用の素材を残す：決定（2026-11-20）。SharePoint の入稿のフォルダーに、文字起こし・動作の表（`読み取り.md`）と、動作ごとの小さなコマの画像（`動作<番号>.jpg`）を置く（`CLAUDE.md` の2）。採用か不採用が決まったら消す（`docs/security.md`）
     - 動画のまま残して読む案は、Microsoft の仕組み（Graph API）に直接つなぐ準備ができたら切り替える（`03_完成` に動画を置く件と同じ準備）
     - 画像を置く道具は、画像を会話に通すので、1枚 50KB くらいに抑える（手本の動画で、4秒・8コマで約50KB、手元の動きは読み取れた）
- 関係：`CLAUDE.md` の2、`docs/rules/photo.md`
