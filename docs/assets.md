# 声とアバターの置き場所のルール

2026-11-20 に高田さんと決めたこと。

## 1. 置き場所

- GitHub の非公開リポジトリ `e24c/copresiden-assets`（全お客様で1つ）
- このリポジトリ（`copresiden`、公開）には置かない
- 学習に使った元の録音・写真・同意書は、これまでどおり SharePoint `<顧客コード>/02_素材`

## 2. フォルダーとファイル名

```
copresiden-assets/
├─ <顧客コード>/
│   ├─ README.md              作った日、作った工程、使うスタイル名、話す速さ、テスト版かどうか
│   ├─ voice/                 Style-Bert-VITS2 の学習済みモデル
│   │   ├─ model.safetensors
│   │   ├─ config.json
│   │   └─ style_vectors.npy
│   └─ avatar/
│       ├─ <服>/              服ごと。名前は series.md の「色・アバターの服」と同じ（例：gray、white）
│       │   ├─ open.jpg       目を開き、口を開けている（話している・声が大きい）
│       │   ├─ half.jpg       目を開き、口は半開（話している・声が小さい）
│       │   ├─ closed.jpg     目を開き、口は閉じている（黙っている）
│       │   ├─ blink.jpg      目を閉じ、口を開けている（まばたき）
│       │   ├─ point.jpg      指差しポーズ（オープニング）
│       │   ├─ point_blink.jpg 指差しポーズで目を閉じる（あれば。オープニングのまばたき）
│       │   └─ welcome.jpg    こちらへポーズ（締め）
│       └─ fullbody.jpg       全身
│   └─ backgrounds/
│       └─ series1.jpg        シリーズの背景（テンプレートにシリーズ名を入れたもの。series1〜3）
└─ …
```

- ファイル名は固定。動画を作るシステムはこの名前で読む
- アバター画像：JPEG か PNG（拡張子は `.jpg` か `.png`。背景が透明な PNG が望ましい）。同じ服の画像は、大きさ・体の位置・肌の色味・顔の形をぴったり揃える（違うと口を切り替えるたびにちらつく）。高さ1000px以上
- 無いポーズは、動画を作るシステムが近いもので代用する（例：welcome が無ければ point）
- 作り直したら同じ名前で上書きする（前の版は Git の記録に残る）
- 鍵・パスワードは置かない

## 2-2. シリーズの背景（2026-11-20）

- テンプレート：縦長 1080×1920 の JPEG。上に「シリーズ名」の見本の文字が入っている。いまは `C0001/Series/1.jpg`〜`12.jpg`（全お客様で使うなら、いちばん上の `Series/` に移す）
- 実運用：お客様にテンプレートを選んでもらい、シリーズ名を決めてもらう → お客様ごとに背景を作り、`<顧客コード>/backgrounds/series<番号>.jpg` に置く。どのテンプレートを使ったかは `series.md` の「背景」に書く
- 作り方：見本の文字を消し（まわりの模様で埋める）、同じ位置・傾き・色でシリーズ名を入れる。11.jpg は傾き約8度、文字は上から120〜290pxの帯
- 動画では、シリーズ名の帯の下（上から330px）から写真・問いかけを置く。左右の枠線（42px）の内側に収める
- 台本JSONの `background`（例：`"series1"`）で選ぶ

## 3. 動画を作るシステムとの受け渡し

- 声：台本の文章を声のモデルに入れて、毎回読み上げの音声を作る。ライブラリの版はモデルを作った版に合わせる（`<顧客コード>/README.md` に書く）
- アバター：読み上げの音声の大きさで open／half／closed を切り替え、ときどき blink をはさむ。オープニングは point、締めは welcome
- 声とアバターをどう作るか（学習・撮影・画像生成）は、このルールの外。決まった場所に決まった名前で置けばよい

## 4. 解約したお客様のデータを消す（毎月）

Git は、ファイルを消しても記録に中身が残る。完全に消すには、リポジトリを作り直す。

- 毎月1回、前の月に解約したお客様がいたときだけ行う（いなければしない）。解約から完全に消えるまで、最大で1か月ほどかかる
- 手順
  1. 高田さん：GitHub で非公開のリポジトリ `copresiden-assets-new` を作る
  2. Claude：今のリポジトリから、解約したお客様のフォルダーを除いた最新のファイルだけを、`copresiden-assets-new` に入れる（記録は引き継がない）
  3. Claude：新しいリポジトリで動画が作れることを確かめる
  4. 高田さん：古い `copresiden-assets` を消し、`copresiden-assets-new` の名前を `copresiden-assets` に変える
- 作り直すと、今いるお客様の古い版も消える（戻せるのは作り直したあとの版だけ）
- 消した日を顧客台帳の「解約メモ」に書く
