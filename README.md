# 社長の副操縦士（CoPresiden）

社長がスマホから送った一言や参考動画をもとに、本人の声とアバターでショート動画を作り、承認後に投稿する仕組みです。
運営：bitgate株式会社。いまは検証段階で、お客様はA.EN（シミュレーション）の1社です。

## 流れ

1. 録って送る：お客様が入稿フォーム（Jotform）で型を選び、一言や画面収録を送る
2. 置き場に入る：ファイルはSharePointの `01_入稿` に自動で届く
3. 夜に作る：Claudeの定期タスクが台本・写真・声・動画を作る（手順は `CLAUDE.md`）
4. 朝に知らせる：メールで動画のリンクと承認ボタンを届ける
5. 承認する：出す／直す／出さない を選ぶ
6. 予約投稿：承認された動画だけを予約する

## フォルダー

| フォルダー | 中身 |
| --- | --- |
| `CLAUDE.md` | 夜の処理の手順 |
| `docs/` | 全お客様に共通のルール（表現、裏取り、デザイン、安全） |
| `templates/` | 投稿の型（5パターン） |
| `engine/` | 動画を作る部品（これから作る） |
| `customers/_template/` | 新しいお客様の台帳とシリーズ設定のひな形 |
| `customers/<お客様>/` | お客様ごとの台帳、シリーズ設定、声のモデル |

## 守ること

- パスワード、APIの鍵、アクセストークンはこのリポジトリに書かない
- 声のモデルとお客様のデータは共有しない。解約のときは消すか返す
- 投稿・送信は、お客様の承認を得たものだけ
